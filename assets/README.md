# دارایی‌های انتشار و رسانه

این پوشه دارایی‌هایی را نگه می‌دارد که برای معرفی، انتشار و پشتیبانی محصول لازم است. دارایی‌های بصری اصلی (نشان، آیکون‌ها، توکن‌ها) در `packages/brand/` قرار دارند و اینجا فقط نسخه‌های آماده انتشار و متن‌های همراه می‌آید.

```
assets/
  demo/60s-demo-script.md     سناریوی ویدئوی معرفی ۶۰ ثانیه‌ای (وب، ویندوز، موبایل)
  press/fact-sheet.md         برگه معرفی محصول برای فروش و پشتیبانی
  press/screenshots.md        راهنمای تولید تصاویر رسمی
```

## تولید دوباره تصاویر

```bash
pnpm exec playwright install chromium
pnpm --filter web screenshots      # خروجی در docs/screenshots
```

تصاویر شامل هر صفحه در سه حالت است: روشن، تیره و موبایل (۳۹۰×۸۴۴).

## دارایی‌های بسته انتشار

| فایل                                        | منبع                                              |
| ------------------------------------------- | ------------------------------------------------- |
| `Dastmozd-Setup-<version>.exe`              | جریان `Release desktop app`                       |
| `Dastmozd-Portable-<version>-x64.exe`       | همان جریان (فایل اجرایی بدون نصب)                 |
| `Dastmozd-<version>-arm64.dmg` و `-x64.dmg` | همان جریان (مک)                                   |
| `latest.json`                               | `apps/desktop/scripts/build-updater-manifest.mjs` |
| آیکون‌ها و تصویر OG                         | `pnpm brand:icons`                                |

## قواعد انتشار تصاویر

- هر تصویر باید از داده نمونه ساخته شود؛ **هرگز** داده واقعی کارکنان در تصویر یا ویدئو نمایش داده نشود.
- نام فایل‌ها لاتین و با خط تیره: `dashboard-light.png`، `payroll-wizard-mobile.png`.
- نسبت تصویر: تصاویر دسکتاپ در عرض ۱۴۴۰ پیکسل و موبایل در عرض ۳۹۰ پیکسل.
- در متن‌های همراه، واحد پول همیشه ذکر شود (ریال) و ارقام با جداکننده هزارگان نوشته شوند.
