# دستمزد ۱۴۰۵

یک محاسبه‌گر حرفه‌ای، راست‌چین و تک‌فایلی برای تهیه فیش حقوق کارگران و کارکنان ایرانی. برنامه بدون نیاز به نصب، سرور یا ارسال اطلاعات به اینترنت، در مرورگر اجرا می‌شود.

## قابلیت‌ها

- محاسبه زنده **حقوق پایه متناسب با کارکرد**، مزایای ثابت، حق اولاد، اضافه‌کاری، شب‌کاری، کار در جمعه و پاداش.
- محاسبه شفاف **مالیات پلکانی** همراه با نمایش سهم هر پله.
- محاسبه بیمه سهم کارمند، سهم کارفرما، سقف بیمه قابل تنظیم و هزینه واقعی کارفرما.
- امکان تعیین پرداخت‌های معاف از مالیات، بیمه تکمیلی، مساعده و سایر کسورات.
- کنترل‌های هوشمند برای مزد کمتر از حداقل، کارکرد نامعتبر، سقف بیمه و خالص منفی.
- ذخیره پروفایل کارکنان و حداکثر ۵۰ فیش در `localStorage` همان مرورگر.
- بارگذاری فیش‌های ثبت‌شده، خروجی JSON و CSV، فیش چاپی A4، حالت تیره و نمایش ریال/تومان.
- طراحی واکنش‌گرا، دسترس‌پذیر و بدون وابستگی به کتابخانه یا CDN خارجی.

## پروفایل پیش‌فرض مقررات

پروفایل اولیه روی سال **۱۴۰۵** قرار دارد و همه ارقام از پنجره «مقررات» قابل بازبینی و تغییر هستند:

| مورد | مقدار پیش‌فرض |
| --- | ---: |
| حداقل مزد روزانه | ۵٬۵۴۱٬۸۵۰ ریال |
| حق مسکن | ۳۰٬۰۰۰٬۰۰۰ ریال |
| بن / کمک‌هزینه اقلام مصرفی | ۲۲٬۰۰۰٬۰۰۰ ریال |
| پایه سنوات ماهانه | ۵٬۰۰۰٬۰۰۰ ریال |
| حق تأهل ماهانه | ۵٬۰۰۰٬۰۰۰ ریال |
| حق اولاد | ۳ برابر حداقل مزد روزانه برای هر فرزند |
| بیمه سهم کارمند / کارفرما | ۷٪ / ۲۳٪ |
| معافیت مالیاتی ماهانه | ۴۰۰٬۰۰۰٬۰۰۰ ریال |
| پله‌های مالیات | ۰٪، ۱۰٪، ۱۵٪، ۲۰٪، ۲۵٪ و ۳۰٪ |

> **نکته حقوقی:** این نرم‌افزار ابزار محاسباتی است، نه جایگزین بخشنامه، قرارداد یا تأیید حسابدار. پیش از ارسال لیست مالیات یا بیمه رسمی، ارقام و اقلام مشمول/معاف را با مصوبات و بخشنامه‌های ابلاغی همان ماه تطبیق دهید. پنجره «مقررات» برای اعمال همین تغییرات طراحی شده است.

## اجرا

فایل `index.html` را مستقیماً در یک مرورگر مدرن باز کنید. برای اجرای یک وب‌سرور محلی نیز می‌توان از دستور زیر استفاده کرد:

```bash
python3 -m http.server 8080
```

سپس آدرس `http://localhost:8080` را باز کنید.

## حریم خصوصی و نگهداری اطلاعات

اطلاعات کارمندان، تنظیمات و سوابق فیش فقط در `localStorage` مرورگر ذخیره می‌شوند و هیچ درخواست شبکه‌ای از طرف برنامه ارسال نمی‌شود. پاک‌سازی داده‌های سایت در مرورگر، این اطلاعات را حذف می‌کند؛ برای آرشیو، از دکمه خروجی JSON یا CSV استفاده کنید.
