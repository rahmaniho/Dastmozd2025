# مبنای قانونی و پارامترهای سالانه

این سند مرجع ارقام و قواعدی است که موتور محاسبه به کار می‌برد. همه مقادیر در `packages/legal/src/profiles/` تعریف شده‌اند و از «تنظیمات ← پارامترهای سال» قابل بازبینی و بازنویسی هستند.

> ⚠️ **هشدار مهم:** ارقام این جدول‌ها از منابع عمومی (متن مصوبه شورای عالی کار، بخشنامه‌های مالیاتی و راهنماهای حسابداری) گردآوری شده است، نه از نسخه رسمی ابلاغی. پیش از هر ارسال به سازمان تأمین اجتماعی یا سازمان امور مالیاتی، مقادیر را با **آخرین بخشنامه و مصوبه ابلاغی همان سال** تطبیق دهید. این نرم‌افزار ابزار محاسباتی است و مسئولیت تطبیق قانونی بر عهده کاربر است.

## ساختار پروفایل

```ts
interface LegalProfile {
  year: number; // سال شمسی
  verified: boolean; // آیا ارقام با بخشنامه رسمی تطبیق شده است؟
  minDailyWage: number; // حداقل مزد روزانه (ریال)
  minMonthlyWage: number; // حداقل مزد ماهانه
  housingAllowanceMonthly: number;
  groceryAllowanceMonthly: number; // بن خواربار
  marriageAllowanceMonthly: number; // حق تأهل
  childAllowanceDaily: number; // حق اولاد روزانه (ضرب در روزهای کارکرد)
  seniorityBaseMonthly: number; // پایه سنوات ماهانه
  insurance: { employeeRate; employerRate; unemploymentRate; ceilingMultiplier };
  tax: { monthlyExemption; brackets: TaxBracket[]; flatSegments: FlatSegment[] };
  overtimeMultiplier: number; // ۱٫۴
  nightShiftMultiplier: number; // ۱٫۳۵
  fridayHolidayMultiplier: number; // ۱٫۴ (+ اضافه‌کار)
  monthlyWorkHours: number; // ۲۲۰ ساعت
  dailyConversionFactor: number; // ۷٫۳۳
  leave: { annualPaidLeaveDays: 26; sickLeaveFirstDaysUnpaid: 3 };
}
```

`resolveLegalProfile(year)` در `packages/legal/src/registry.ts` نزدیک‌ترین پروفایل موجود را با گزارش `fallback` و `warning` برمی‌گرداند؛ بنابراین محاسبه هرگز بی‌صدا با پروفایل اشتباه انجام نمی‌شود.

## مرخصی و سنوات

- مرخصی استحقاقی سالانه: ۲۶ روز کاری؛ در محاسبه ماهانه به نسبت کارکرد محاسبه می‌شود.
- سه روز نخست مرخصی استعلاجی بدون پرداخت (بر پایه تنظیم پیش‌فرض پروژه) و مابقی مشمول قواعد تأمین اجتماعی.
- پایه سنوات در پروفایل ۱۴۰۵ ماهانه ۵٬۰۰۰٬۰۰۰ ریال (روزانه ۱۶۶٬۶۶۷ ریال) و در محاسبه، هنگام احراز شرط یک سال سابقه کامل کارکرد اعمال می‌شود.
- عیدی پایان سال پس از ۱۱ ماه کارکرد محاسبه می‌شود و سقف معافیت مالیاتی آن معادل یک دوازدهم معافیت سالانه است.

## بازنویسی پارامترهای سال

اگر بخشنامه‌ای پس از انتشار نرم‌افزار ابلاغ شود، بدون تغییر کد می‌توان ارقام را اصلاح کرد:

1. در «تنظیمات ← پارامترهای سال» مقادیر را اصلاح و ذخیره کنید (رکورد `LegalOverrideRecord` با تاریخ و کاربر ثبت‌کننده در پایگاه‌داده نگه‌داری می‌شود).
2. دوره حقوقی را دوباره اجرا کنید؛ نسخه جدید با `meta.legalProfileHash` تازه ساخته می‌شود و نسخه‌های پیشین دست‌نخورده می‌مانند.
3. برای پروفایل سال‌های آینده، فایل `packages/legal/src/profiles/<year>.ts` را بر پایه پروفایل سال گذشته بسازید و در `registry.ts` ثبت کنید؛ آزمون `legal` باید مقادیر را پوشش دهد.

## پوشش آزمون قوانین

```bash
pnpm --filter @dastmozd/legal test     # صحت ساختار پروفایل‌ها و پلکان‌ها
pnpm --filter @dastmozd/core test      # عددهای مرجع ریالی هر سناریو
```

عددهای مرجع در `packages/core/src/__tests__/payroll.test.ts` و `rates.test.ts` نگهداری می‌شوند؛ هر تغییر در پروفایل‌ها که نتیجه را جابه‌جا کند، آزمون را می‌شکند و نیازمند بازبینی دستی حسابدار است.
